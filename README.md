### 项目开发进展 - bird-os

---

#### **项目起步** - 2024年11月13日

**项目目标：**

- 基于 xv6 操作系统的架构，开发一个简化、模块化的操作系统，名为 bird-os。
- **功能目标：** 提供基本的操作系统功能，如进程管理、内存管理、文件系统和设备驱动等。
- **学习目标：** 通过开发，进一步理解操作系统原理和体系结构。

**技术选型：**
- 基于 xv6 操作系统，适合扩展与学习。
- 采用 RISC-V 架构，增强系统的可移植性和现代硬件支持。
- 编程语言：C语言（与 xv6 保持一致）。

---

#### **第一阶段：基础系统架构搭建** - 2024年11月15日

**搭建开发环境：**
- 安装并配置了 RISC-V 工具链和 QEMU 模拟器，确保能够构建和运行 xv6。
- 成功克隆了 xv6 源代码并成功编译和运行。
- 配置了本地开发环境，包括 IDE（如 VS Code 或 Vim）和必要的调试工具。

**系统架构设计：**
- 在 xv6 基础上，设计了 bird-os 的初步架构，确保其能够在 RISC-V 架构上顺利运行，并且能支持后续模块和特性的添加。

---

#### **第二阶段：改进模块设计，完善系统功能** - 2024年11月17日

**进展：**
- 11/17： 
  - 实现 `SYS_cps` 系统调用，能够查看当前系统的进程信息（包括进程名、PID、优先级等）。
- 11/20
  - 实现系统调用SYS_trace，指定要跟踪的系统调用

- 11/21：
  - 实现系统调用SYS_sysinfo,可以查看当前进程数量，以及剩余空闲内存
  - **内存管理：** 实现写时分配技术（Copy On Write）
- 11/24：
  - **优化锁机制** 将空闲页面链表和Buffer cache 的锁进一步细化，减小锁的颗粒度，提高并行效率
- 11/25：
  - **内存管理：** 修改系统调用SYS_bark并实现懒分配
  - 改写相关用户测试程序

该阶段的目标是改进操作系统的核心功能和实现更复杂的系统调用。在添加新功能后，系统的可扩展性和可维护性也得到了提升。
