开发路程：bird-os

项目起步 - 2024年11月13日


确定项目目标：

基于 xv6 操作系统的架构，开发一个简化、模块化的操作系统，名为 bird-os。

bird-os 将具备基本的操作系统功能，如进程管理、内存管理、文件系统和设备驱动等。
项目目标不仅是实现一个操作系统，更是通过该项目进一步理解操作系统原理和体系结构。



技术选型：

基于 xv6 操作系统，它采用了简洁的 Unix v6 样式，适合进行扩展和学习。
使用 RISC-V 架构，以提高系统的可移植性和现代硬件支持。
编程语言：C语言（与 xv6 保持一致）。




第一阶段：基础系统架构搭建 - 2024年11月15日


搭建开发环境：

安装并配置 RISC-V 工具链 和 QEMU 模拟器，确保能够构建和运行 xv6。
克隆 xv6 源代码并成功编译和运行。
配置本地开发环境，包括 IDE（如 VS Code 或 Vim）和必要的调试工具。



系统架构设计：

在 xv6 的基础上，设计 bird-os 的初步架构。确保系统能顺利运行在 RISC-V 架构上，并且后续能添加模块和特性。
